BeautyFlow — презентация проекта

Откройте index.html. Для публикации на GitHub Pages распакуйте и загрузите ВСЕ файлы и папку assets целиком, сохраняя структуру архива. Один index.html отдельно не содержит CSS, JavaScript и снимки экранов.

Управление: стрелки/пробел — слайды; Home/End — первый/последний слайд; T — тема; F — полный экран. Текст выступления находится в speech.txt.

Кнопка «Открыть приложение» ведёт на https://beautyflowy.vercel.app.
